# MyNetFlix

Um site-presente com cara de tela de filme, feito para contar a historia de um casal.

## Como personalizar as fotos

Para que as fotos aparecam para qualquer pessoa que abrir o link, coloque estes arquivos na pasta `dist/assets/`:

- `capa.jpg`: foto grande de fundo
- `poster.jpg`: foto vertical para a capa do filme

Depois disso, envie as alteracoes para o GitHub. O GitHub Pages atualiza o link automaticamente.

Tambem da para testar fotos e textos direto no site usando os botoes de edicao. Essa edicao fica salva apenas no navegador onde foi feita.
